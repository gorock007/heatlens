## What the user asked
A fixed shortcut, ⌃⌥H, that opens the panel or closes it when it's open. It's off by default, has
a switch in Settings, and adds no package dependency. Also a Debug-only `-HeatLensFixtures YES`
launch argument, so fixture UI can be clicked through in the real app.

## What changed
- **`App/GlobalHotkey.swift`** (new): registers ⌃⌥H with Carbon's `RegisterEventHotKey` plus an
  `InstallEventHandler` on the application event target, so no Accessibility permission is needed.
  - It follows `settings.globalHotkeyEnabled` with `withObservationTracking`, as
    `ThermalAlertService` does. It registers while the setting is on and removes both the hot key
    and the handler as soon as the setting is turned off. `deinit` removes them too.
  - The handler checks the hot key ID (signature `'HLhk'`, id 1) and calls the action on the main
    actor.
  - If registration fails with any non-`noErr` status (normally because another app holds ⌃⌥H),
    it sets `settings.globalHotkeyConflict = true`. Unregistering clears it.
- **StatusPanel**: `toggle()` is no longer `private`. It's still `@objc`, because the icon uses
  it as its action. That's the whole change.
- **Settings**:
  - `SettingsModel.globalHotkeyEnabled` is stored in UserDefaults and defaults to `false`.
  - `globalHotkeyConflict` is in memory only and observable.
  - Settings has an "Open HeatLens with ⌃⌥H" toggle right under the thermal alert row, in the
    same layout. When the setting is on and registration failed, the row shows "⌃⌥H is already
    used by another app" in orange caption text.
- **`-HeatLensFixtures YES`** (Debug only, `#if DEBUG` in `AppDelegate`): uses
  `FixtureScanService()` and `FixtureStopService()` instead of the pipeline and terminator
  services. `AppDelegate` now creates one `SettingsModel` and shares it between `ScanModel` and
  `GlobalHotkey`, so it's still a single settings instance.
- **README**: one Privacy bullet, right after 10a's thermal alert bullet.
