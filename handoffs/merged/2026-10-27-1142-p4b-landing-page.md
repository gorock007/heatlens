## What the user asked
A production-quality static landing page in `site/` (no build step, Vercel root dir `site`)
for HeatLens as a free macOS menu-bar app: hero with the tagline and a Download for Mac button,
an HTML/CSS recreation of the popover, how it works, what it shows, safety and privacy, honest
limits, FAQ, footer, favicon, og.png, meta tags, `vercel.json` with security headers. Every
claim traceable to the repo's docs; no screenshots or real `ps` output from this Mac.

## What changed
New `site/` directory, nothing else touched. No JavaScript at all; FAQ uses `<details>`.

- **Hero** is a flat "desk" panel with a faux macOS menu bar (thermometer extra highlighted)
  and the results popover hanging under it, headline left. The popover is a 300 px CSS
  recreation of `PopoverView`/`ResultsView`/`FindingCard` using only the synthetic
  `FixtureScanService` data (OpenCode agent 44%, worker.js PID 12874 2d 5h, 3.2 of 11 cores,
  8.5 GB of 10 GB swap). Labels, chips, section titles, button names and the bottom row
  (Copy report / Copy JSON / Done / Scan again / Quit HeatLens) match the Swift source.
- **How it works**: three steps, each with a small faithful mock (idle popover with "Last
  scan: never" and "Nothing is monitored until you scan."; scanning popover with "Measuring
  process activity (7 of 10 seconds)"; a Review finding card with evidence expanded).
- **What it shows**: active work vs leftovers, project attribution, thermal/memory state.
- **Safe by construction**: offline, read-only, SIGTERM-only confirmed stop, protected
  processes (names from `ProcessTerminator.protectedNames`), with the `StopFlowView`
  confirmation sheet recreated at 330 px.
- **What it can't tell you**: five items from `docs/LIMITATIONS.md`, link to the full file.
- **FAQ**: Gatekeeper/notarization (with the `spctl` check from the 4a brief), why no
  permissions and what it can't see, background/idle footprint (numbers from
  `docs/PERFORMANCE.md`), what Request stop does, why not sandboxed/App Store, uninstall
  (`~/Library/Preferences/dev.heatlens.HeatLens.plist` from `project.yml`), Intel.
- **Download band + footer** with GitHub, Releases, Issues links.
- Theme: `:root` tokens, dark values under `prefers-color-scheme: dark` (also honoured via
  `data-theme`). System font stack only. Reduced motion respected (only motion is the FAQ
  chevron and smooth anchor scroll). Skip link, landmarks, `role="img"` + `aria-label` on each
  mock with the inner markup `aria-hidden`, visible focus rings, contrast ≥ 4.5:1 on page text.
- `vercel.json`: `cleanUrls`, CSP (`default-src 'self'`, no inline styles/scripts needed),
  `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options`, `Permissions-Policy`.
- `site/.vercelignore` excludes `og.html` (the og.png source) from deployment; it is not linked
  from the page.
