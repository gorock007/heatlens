## Goal
User ruling (2026-10-27): a **fixed** shortcut, **⌃⌥H**, that opens the panel, or closes it when it's open. It's **off by default**, there's a switch in Settings, and **no new package dependency**. Done means:
1. **The hotkey.** Add `App/GlobalHotkey.swift`, which registers ⌃⌥H with Carbon's `RegisterEventHotKey` / `InstallEventHandler`.
   - Carbon needs no Accessibility permission. Don't use an `NSEvent` global monitor, which does need it.
   - It registers only while the setting is on and unregisters at once when the setting is turned off. Follow the setting the way `App/ThermalAlertService.swift` does, with `withObservationTracking`.
   - If registration fails because another app holds ⌃⌥H, keep the error so Settings can show it.
2. **Panel.** Pressing the hotkey calls `StatusPanelController`'s existing `toggle()`. Make it callable (it's `@objc private`) with the smallest change, next to `show()` from 10a.
3. **Settings.**
   - Add `SettingsModel.globalHotkeyEnabled`, stored in UserDefaults, default `false`.
   - In `App/SettingsView.swift`, add a toggle "Open HeatLens with ⌃⌥H". Place it near the thermal alert row and match its layout.
   - When registration failed, show "⌃⌥H is already used by another app" under the toggle.
4. **Debug fixtures launch argument.** In `App/HeatLensApp.swift`, add `#if DEBUG`-only handling of `-HeatLensFixtures YES`. With it, `AppDelegate` uses `FixtureScanService()` and `FixtureStopService()` instead of the pipeline and terminator services, so the leftovers batch sheet (10b) and other fixture UI can be clicked through in the real app without stopping anything. It must not exist in Release: check with `strings`, as 10a did for its flag.
5. **README.** Add one feature line next to 10a's Privacy bullet, or under Status.
