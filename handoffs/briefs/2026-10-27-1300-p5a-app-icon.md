## Goal
HeatLens v1.0.0 shipped with no app icon: Finder, the DMG and the Dock all show the generic blank app. Design a proper macOS app icon and wire it into the build. Done means:
- `App/Assets.xcassets/AppIcon.appiconset` has every macOS size (16, 32, 128, 256 and 512 at @1x and @2x, so 16–1024 px)
- the Release build contains `Contents/Resources/AppIcon.icns`
- Finder shows the icon for `.build/xcode/Build/Products/Debug/HeatLens.app`

## Context
- There's no previous icon handoff. The release pipeline handoff is `handoffs/merged/2026-10-27-1145-p4a-release-pipeline.md`, and another worker is editing `scripts/release.sh` at the same time, so don't touch it.
- **Brand to match:**
  - The landing page mark is `site/favicon.svg`: a thermometer outline with red mercury.
  - Palette from `site/styles.css`: ink `#1b1b1f`, mercury `#d63f2a`, accent `#0a62d6`, light bg `#f3f3f5`.
  - The menu-bar icon is SF Symbol `thermometer.medium` (`App/HeatLensApp.swift:13`).
  - The product idea is "a lens on what's heating your Mac". A thermometer, optionally combined with a lens or magnifier, works. Keep it simple and readable at 16 px.
- **macOS icon conventions:**
  - Use the Big Sur-and-later rounded-square shape: about an 824×824 body on a 1024 canvas, with a transparent margin and a subtle drop shadow.
  - It must look like a native Mac utility next to Activity Monitor and System Settings, not like a flat web favicon.
- Build it from a vector or code source you keep in the repo (`App/Icon/heatlens-icon.svg`, plus a short script, `scripts/make-icon.sh`, that renders every PNG size from it with `rsvg-convert`, `sips` or a small Swift/Python script, whichever is installed). Then the icon can be regenerated instead of hand-edited. If you use an image model for the artwork, still commit the final master PNG (`App/Icon/heatlens-icon-1024.png`) and generate the sizes from it with the script.

- **Patterns to copy:**
  - `scripts/make-icon.sh` follows `scripts/run-app.sh` (`set -euo pipefail`, `cd "$(dirname "$0")/.."`, quiet tools with a tail on failure).
  - Shape the icon on the system's own `/System/Applications/Utilities/Activity Monitor.app/Contents/Resources/AppIcon.icns`: open it to compare margin, shadow and corner radius.

## What to do
1. Make 2 or 3 candidate concepts as 1024 px PNGs in your scratch folder. Pick the strongest one using the rules above, and say why in the handoff, listing the paths of all the candidates.
2. Produce `App/Icon/` (source and master), `scripts/make-icon.sh` and `App/Assets.xcassets/AppIcon.appiconset/` (PNGs plus a `Contents.json` with the standard mac idioms). Also add the root `App/Assets.xcassets/Contents.json`.
3. In `project.yml`, add `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` to the HeatLens target's settings. Make sure xcodegen includes `Assets.xcassets` as a resource (it's under `App/`, which is already a source path). Check this in the build output; don't assume it.
4. Leave the `site/` files alone; Jarvis decides later whether the site uses the new icon.
